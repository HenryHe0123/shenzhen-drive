# 版本记录 / Changelog

## v0.1.0 — 首个可玩版本（进行中）

### 新增
- 城市数据管线：从 OSM 提取深南大道东行中心线，在直线段剪切拼接到真实长度的约 72%，输出路线、检查点、终点前左转和沿线建筑（`scripts/build_city_data.py`）。
- 可自由驾驶的小米 SU7：简化运动学、道路边界碰撞、倒计时、顺序检查点、计时、最佳成绩、HUD 和 `?debug` 调试模式。
- 黄昏城市场景：道路与道路设施、OSM 建筑、地标、天空与后处理。
- 程序化 Web Audio 音效：电机啸叫（音高随车速）与逆变器高频音、风噪、胎噪、碰撞闷响、倒计时提示音、检查点 / 终点音。
- 测试：Vitest 路线投影与数据校验；Playwright 冒烟测试和音频测试，截图保存在 `evidence/`。

### 已知问题
- 弯道上离开中心线时，`Route.project` 不是 `Route.pointAt` 的精确逆运算：s 误差最大约 |d|·h/(2R)（终点前 R≈20–30 m 的转弯处，d = ±7 m 时约 0.23–0.35 m），d 误差小于 1 cm，对碰撞无实际影响。
