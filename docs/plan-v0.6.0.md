# v0.6.0 全城场景：现状与反馈清单

目标：跑道仍是深南大道这一条，不动；在它之外建出整个深圳市的 3D 场景，先尽量用公开数据做出第一版，再按人的反馈逐步修正。第一版已完成，逐项细节和实测数据见 [CHANGELOG.md](CHANGELOG.md) v0.6.0。

## 第一版做了什么

| 部分 | 数据 | 做法 |
|---|---|---|
| 地形 | Copernicus GLO-30（30 m） | 城区去掉建筑凸起；路线 320 m 内压平，900 m 外是真实标高；范围含香港新界、东莞、惠州边缘 |
| 海与水体 | Overture `water`（源自 OSM） | 海、深圳湾、水库、河流按真实岸线建成水面，地形在水下刻低 |
| 地面 | Sentinel-2（2025-03） | 去云合成、去掉影像自带的山体阴影，24 m / 像素 |
| 建筑 | OSM + Overture 机器学习屋顶 | 深圳市内 451,826 栋；近处挤出立面，远处实例化体块 |
| 建筑高度 | OSM 标注 + 估算模型 | 有标注的用标注（约 1.5 万栋），其余由按深圳已标注建筑训练的模型估算 |
| 道路、铁路 | OSM | 5.9 万条，贴地；桥梁、高架有桥面和桥墩 |
| 巡览 | — | `explore.html`，自由飞行，18 个预设视点，双击拾取坐标和楼高 |

比赛画面、手感、计时和沿线 300 m 内的场景没有改。

## 怎么看

- 开始界面点“全城巡览”，或打开 `explore.html`。面板上的按钮（或 1–9 键）跳到各区视点，T 切换白天 / 日落。
- 想对比改动前的样子：任意页面加 `?noMetro`。
- 看到不对的地方，双击它：面板和浏览器控制台会给出经纬度、海拔和楼高，例如 `{"lon":114.061493,"lat":22.525598,"height":0,"note":"地面海拔 6 m · 建筑高约 107 m（全城）"}`。把 `height` 改成真实高度发给 agent，就能加进 `scripts/city_config.json` 的 `metro.heightOverrides`，重跑管线即生效。

## 请重点看这些

1. **楼的高度**（最没把握的部分）。约 97% 的建筑高度是估算的，没人标注的地区高楼误差中位数约 39 m，低矮建筑可能被估高。请看你熟悉的片区：
   - 住宅塔楼群（龙华、宝安、龙岗、南山）有没有明显太矮或太高；
   - 城中村（白石洲、岗厦、水围、南头、沙井等）是不是该有的密、矮；
   - 工业区（宝安、龙华、光明）厂房是不是被估成了高楼；
   - 你知道名字的高楼有没有不对（双击拾取后告诉 agent 真实高度）。
2. **少了或多了的建筑**：Overture 的机器学习屋顶有遗漏和误检，特别是新建成的片区（前海、深圳湾超级总部、留仙洞）。
3. **地形和海岸**：山的形状、海岸线、水库位置；路线附近 320 m 内地形是压平的，这是有意的。
4. **画面观感**：雾 / 霾浓不浓、海水颜色、远处楼的颜色、卫星地面近看太糊是否能接受。
5. **比赛里**：开一遍，看沿线是否和 v0.5.0 一样，远处有没有奇怪的东西；如果你的电脑上帧率下降，告诉 agent。

## 可选的下一步（按反馈再定）

- 按反馈修高度：`metro.heightOverrides` 逐栋修，或按片区调整估算模型。
- 香港、东莞也放建筑（Overture 有数据，约多 30 万栋），让深圳湾对岸和北边地平线不再是空的。
- 地标的专门模型：华润春笋、深圳湾大桥斜拉塔、宝安机场 T3、深中通道等，目前都是挤出的方块或普通桥面。
- 山上和公园里的三维树木（目前只有卫星图的颜色）。
- 更清晰的地面：近处按需加载更高分辨率的影像块。
- 更真实的立交和高架高度（目前按 OSM `layer` 估）。
- 画质档位：在较弱的电脑上减少全城场景的加载半径。
